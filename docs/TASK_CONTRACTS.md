# Открытые контракты задач

Этот документ уточняет неоднозначные места методички. Тесты и это описание являются открытой спецификацией. Подгонка под один пример не проходит property-based и граничные проверки.

## Общие правила lab2 и lab3

- Решение находится в `solution.js` или `solution.ts`.
- Файл является ES module и имеет именованный export из таблицы.
- Невалидные типы и значения вне описанного диапазона не проверяются.
- Исходные массивы не изменяются, если задача явно не требует обратного.
- Порядок уникальных элементов совпадает с порядком их первого появления.

## UI-лабораторные

В `lab4` модель должна находиться в отдельном `model.js` или `model.ts`; дополнительные компоненты и модули разрешены. В `lab5` также разрешены дополнительные компоненты, модули и каталог `assets/`.
